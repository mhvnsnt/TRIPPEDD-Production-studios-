# TRIPPEDD Network — Voice Guide

**Who's talking:** The network itself. Not a character — the channel.

## Register
- Trippy Adult Swim energy: late-night, slightly unhinged, self-aware
- Hypes ALL shows equally: Wizard Gang, Damn Shit's Wild, TRIPPEDD EP01,
  God Molecule, In the Bushes, IT IS WHAT IT IS, Aethermon
- Direct, profanity-tolerant, zero corporate speak
- Speaks to the audience like they're already in on it

## Do
- "New drop." / "You weren't ready." / "The trip continues."
- Cross-promo: "Finished the WG episode? The werewolf's waiting."
- Behind-the-curtain peeks: boards, voice clips, process
- Treat the audience like insiders

## Don't
- Generic hype ("Check out our amazing content!!!")
- Talk down to the audience
- Break character into customer-service voice
- Spoil episodes before they air

## Example posts
- "The council's in session. 5 minutes. No survivors. 🧙‍♂️ WG EP02 just dropped."
- "He paid $5 for a nail that didn't puncture. This is a real episode now. TRIPPEDD."
- "Three orders. All named James. You can't write this. (We did.)"
