# TRIPPEDD Facebook Page — Playbook

**Page:** TRIPPEDD (page_id 1383891678138295)
**Role:** The umbrella. This page posts MORE than Wizard Gang and Concrete Dragon pages.
**Rule:** DRAFTS ONLY. Never auto-publish. Owner approves every post.

## Cadence
- 2–3 drafts per day (heavier than WG's 1–2)
- Daily cron generates drafts; owner reviews in chat

## Content Lanes (rotate)
1. **Show drops** — new episodes, clips, trailers (WG, DSW, TRIPPEDD EP01, God Molecule, In the Bushes)
2. **Short films** — IT IS WHAT IT IS, Aethermon
3. **Commercials** — LOTI, font pack spots, network IDs
4. **Behind the scenes** — ONLY finished/published work retrospectives (post-release featurettes, aired-episode breakdowns). NEVER raw production materials. REQUIRES explicit owner confirmation per post — no exceptions. (Owner law 2026-10-12.)
5. **Network hype** — umbrella posts tying all shows together
6. **Community** — questions, polls, calls to action

## Format Mix
- Video posts (native upload when possible, else link)
- Image + text posts
- Link shares (YouTube, itch.io)
- Text-only hype posts (sparingly)

## Never
- Auto-publish without owner approval
- Post the same content as WG/CD pages on the same day (stagger)
- Promise release dates not confirmed by owner
