# 🛠️ Storypencil 4.4 Fix by Olst

**Unofficial fix** for the official [Storypencil](https://projects.blender.org/extensions/storypencil) add-on,  
updated for **Blender 4.4+** compatibility before the official version is released.

> 🧩 Storypencil is a powerful tool for creating storyboards directly inside Blender’s 2D animation workspace.

---

---

## ▶️ How to Start

1. In Blender, go to:  
   **File > New > 2D Animation**

2. Switch to **Draw** mode.

3. From the top menu, choose:  
   **Draw > Setup Storyboard Session**
