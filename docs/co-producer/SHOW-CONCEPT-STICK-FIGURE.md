# Co-Producer Show Concept: Stick-Figure Animated Series

## Positioning

A standalone animated show developed inside the TRIPPEDD Productions network, while also being modular enough to appear as recurring segments, shorts, bumpers, interstitials, and crossover material elsewhere in the network.

The visual target is intentionally **simple, cheap, expressive, and weird**: stick-figure animation with crude-but-deliberate staging, deadpan timing, surreal escalation, and strong writing. The goal is to capture the *production philosophy* of low-fi adult animation without copying any existing show's characters, designs, stories, or assets.

## Production Principle

**Write once → build reusable assets → animate with presets → render → publish.**

We should avoid hand-redrawing the same character or background for every shot. Characters, props, locations, expressions, camera moves, and sound cues should be reusable building blocks.

## Streamlined Episode Pipeline

1. **Premise** — one-sentence comic or surreal premise.
2. **Beat sheet** — 8–15 story beats, prioritizing escalation and timing.
3. **Script** — dialogue + action + sound cues, written for limited animation.
4. **Shot list** — each shot gets a reusable character pose, prop, location, camera move, and duration.
5. **Asset pass** — create only missing assets; reuse the library whenever possible.
6. **Animatic** — assemble still poses, mouth swaps, camera moves, and timing before detailed animation.
7. **Animation pass** — animate only moments that benefit from motion; hold poses when comedy benefits from stillness.
8. **Audio pass** — dialogue, room tone, effects, music, pauses, and deliberate silence.
9. **Compositing** — backgrounds, characters, camera framing, effects, titles, and network branding.
10. **QC + export** — verify audio, frame timing, captions, aspect ratios, and delivery presets.

## Reusable Asset System

### Characters

Each recurring character should have:

- neutral standing pose
- 3–5 emotional poses
- 4–6 mouth shapes
- eye variants
- pointing/reaching pose
- walk-cycle or simple movement cycle
- silhouette/color/style reference

### Locations

Build backgrounds as modular layers:

- base environment
- foreground
- movable props
- lighting/effect layer
- alternate time-of-day variants

### Animation Presets

Create reusable presets for:

- head turn
- blink
- mouth swap
- bounce
- walk
- shake
- impact
- reaction snap
- slow zoom
- quick push-in
- pan
- screen shake
- hold/freeze
- simple object rotation

## Format Flexibility

The same production assets should support:

- 11–15 minute standalone episodes
- 5–7 minute mini-episodes
- 1–3 minute TRIPPEDD segments
- 15–60 second shorts
- interstitials/bumpers
- social clips
- cold opens and post-credit tags

## Creative Rule

The animation should **serve the joke and the atmosphere, not compete with them**. Limited animation is a feature when it creates a recognizable rhythm: long holds, awkward pauses, sudden movement, visual repetition, and unexpected escalation.

## Network Integration

The show can exist as its own series while sharing a production universe with TRIPPEDD. Characters or concepts can appear in network segments without making the standalone show dependent on the larger universe.

This gives TRIPPEDD Productions a reusable animated-content engine rather than a one-off cartoon production.
