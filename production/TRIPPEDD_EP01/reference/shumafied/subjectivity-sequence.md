# EP01 Generated Sequence — The Shumafied Experience

## Purpose

This sequence visualizes the character's subjective experience. It is **not** a claim about what the camera physically recorded.

## Language progression

1. **LIVE ACTION** — establish the real character and physical environment.
2. **VISUAL DISTORTION** — subtle spatial/color/motion instability.
3. **ANIMATION** — reality begins obeying cartoon logic.
4. **3D** — camera leaves ordinary physical constraints.
5. **BLENDER / CG** — build impossible geometry, scale, motion, and environmental transformations.
6. **IMPOSSIBLE WORLD** — full subjective release; maximum visual escalation.
7. **???** — optional additional medium only if it increases the joke or subjective meaning.
8. **LIVE ACTION RETURN** — hard cut back to ordinary footage.

## Editorial joke

The audience gets the huge experience. The character does not validate it.

The return beat should permit the character to say, in substance, that the shroomified experience **wasn't even shit**.

## Generation requirements

- Every generated shot gets `provenance = GENERATED`.
- Every generated shot links back to `ep01-lost-acid-subjectivity`.
- Generated shots cannot masquerade as source footage.
- Preserve a clean return point to real footage.
- Do not add psychedelic imagery merely as decoration; every shot must escalate perception, character state, or comedy.
- Prefer short, hard editorial beats over one long demo reel.

## Handoff to tools

- ComfyUI / image generation: concept frames and texture/style exploration.
- Blender: impossible environments, camera motion, geometry, and controlled 3D transformations.
- FFmpeg: conform, transitions, compositing inputs, and final render assembly.
- Audio tools: subjective sound design only after picture intent is locked.

## Approval gate

The autonomous director may draft and generate previews. The showrunner must approve the sequence before it enters the final editorial assembly.
