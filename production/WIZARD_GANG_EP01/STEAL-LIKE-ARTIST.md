## Puppet rig structure (Gumball .fla) — HIGHEST PRIORITY

**Read:** `~/workspace/animation-techniques/steal-like-artist/cn-gigaleak/study-notes/fla-rig-conventions.md`

The actual working files: `GB200_ORIGINAL_PUPPET_GUMBALL_VERSION_008.fla`
- Layer hierarchy: `GB[code]_[CHARACTER]` with descriptive sub-layers
- 30+ body parts nested without chaos
- Symbol nesting strategy (Graphic vs MovieClip for mouths/hands/eyes)
- Registration point placement at joints
- Naming conventions that scale: `GB[code]_[DESCRIPTION]_VERSION_[###].fla`
- Pipeline stages in filenames: REMOTE → Clean → cleanup + artist initials
- 25 FPS, 14:9/6:9 safe guides

**Apply to:** Ashes, Static, Cipher, Echo, Onyx, Sombra, Theory, Kiko, Hollow.
Build every WG character rig following this organization.
