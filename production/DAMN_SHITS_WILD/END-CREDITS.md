# DAMN, SHIT'S WILD — End Credits

**Style:** wavy trippy white-on-black cards (network interstitial language — the STAY TRIPPEDD card family). Cards in `end-credits/`. Reusable per episode: cast card updates with episode-specific voices; crew card stays constant unless the team changes.

## Credit order (per episode)

1. **CAST** — character → voice, in order of appearance
2. **CREW** — the departments
3. **CREATED BY** — Real Marquis Deshaun Whitacre
4. **TRIPPEDD NETWORK** — network end card → STAY TRIPPEDD

## Rules

- No invented names, ever. TBD stays TBD until someone is real.
- The owner's name is the only personal credit; everything else is department-level.
- Cards regenerate per episode only when the cast or crew changes.
- End-credit boards ship with every episode master.
