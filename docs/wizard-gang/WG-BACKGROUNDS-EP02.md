treatments: s26 cropped 2:1 → 16:9; s27 kept at native 2.79:1.

## What UNMATCHED means

UNMATCHED is a holding state, not a rejection. Those 10 plates are page visuals,
future-episode locations, or mood reference — but they are NOT assigned to any
EP02 scene, because the episode gives no evidence for it. If the owner places one,
the table gets updated with his call, not a lane guess.

## Usage — converting WebP → PNG where needed

WebP is the stored format. Convert only the plate you need, at use time
(PNGs are not committed for all 26 plates — that would bloat the docs repo):

```sh
python3 -c "from PIL import Image; Image.open('Group 10 - fireworks.webp').convert('RGB').save('bg_s27_fireworks.png')"
# or: ffmpeg -i "Group 10 - fireworks.webp" bg_s27_fireworks.png
```

For a 16:9 episode frame from a 2.79:1 cartoonier strip, centre-crop the width
to `height × 16/9` first (see the s26 composite: 2240×1120 → 1982×1120 → 1920×1080).
For page/social use, keep native aspect — the strips are composed as wide group
banners and cropping cuts the edge figures.
