## ASSET TYPE GUIDE — What Each Type Teaches You

### 🎭 PUPPET RIGS (.fla) — PRIORITY: HIGHEST
**What:** Adobe Animate source files with fully rigged character puppets.
**Teaches:** Layer hierarchy, naming conventions, symbol nesting, how pros structure movable parts.
**Use for:** Building your own character rigs in Animate. Copy the ORGANIZATION, not the characters.
**Key files:**
- `GB200_ORIGINAL_PUPPET_GUMBALL_VERSION_008.fla` — master Gumball puppet
- Darwin, Anais, Richard Watterson puppets (same naming pattern)
- Scene files: `GB202REMOTE_Sc094_Clean_V023_STN.fla` (pipeline stages visible)

**Observed production conventions:**
- Filename: `GB[code]_[DESCRIPTION]_VERSION_[###].fla`
- Scene files: `GB[code]REMOTE_Sc[###]_[Clean|Cleanup]_V[###]_[INITIALS].fla`
- Timeline: 25.00 FPS
- Safe areas: "14:9 safe" and "6:9 safe" guides
- Layer naming: `GB[code]_[CHARACTER]` with descriptive sub-layers
- Pipeline stages in filename: REMOTE → Clean → cleanup (+ artist initials)
- All body parts on separate layers inside the character symbol (puppeting)

### 📖 SHOW BIBLES — PRIORITY: HIGH
**What:** The canonical creative document for a show. Character backgrounds, world rules, episode formulas.
**Teaches:** How to structure YOUR show bible. Section organization, character entry format, premise writing.
**Use for:** Template for Wizard Gang / Goodville / God Molecule bibles.
**Structure (from Johnny Bravo analysis):** Title → Series Overview (6-step pattern) → Character Applications (standardized) → Environmental Parameters → Story Premises
**Study note:** See `study-notes/bible-structure-analysis.md`

### 📐 MODEL SHEETS — PRIORITY: HIGH
**What:** Character reference sheets — turnarounds, expressions, poses, proportions.
**Teaches:** How many views, what expressions, how proportions are notated, color callouts.
**Use for:** Format reference for your own character model sheets.
**Key detail:** Vehicle/prop sheets seen in Gumball leak — props get the same turnaround treatment.

### 🎬 STORYBOARDS — PRIORITY: MEDIUM
**What:** Panel-by-panel visual scripts for episodes.
**Teaches:** Boarding format, panel layout, action notation, dialogue placement.
**Use for:** Format your own boards the professional way.
**Two pipelines to compare:** Board-driven (Adventure Time, Regular Show — boards ARE the story) vs. script-driven (most others).

### 🎞️ ANIMATICS — PRIORITY: MEDIUM
**What:** Timed storyboard sequences with temp audio.
**Teaches:** How timing is locked before animation begins. Pacing, comedic timing, scene length.
**Use for:** Build animatics for your episodes before committing to full animation.

### 📝 SCRIPTS — PRIORITY: MEDIUM
**What:** Episode scripts ("forgotten scripts" per Clownfish TV).
**Teaches:** Animation script format (different from live-action), action description density.
**Use for:** Writing your own episode scripts in industry format.

### 🏷️ BRAND GUIDES — PRIORITY: MEDIUM
**What:** Style guides for the show's visual identity.
**Teaches:** How pros document color palettes, logo usage, tone.
**Use for:** Building brand guides for your shows/network (TRIPPEDD needs one).

### 🎯 PITCH DOCS — PRIORITY: LOW (but interesting)
**What:** Documents used to sell the show to the network.
**Teaches:** How to pitch YOUR shows. Logline format, comp titles, audience description.

### 📋 PRODUCTION GUIDES — PRIORITY: MEDIUM
**What:** Internal studio documentation (per IndiaTimes).
**Teaches:** How a professional studio documents its pipeline for the team.
**Use for:** Template for documenting YOUR production pipeline.

### 🔤 PRODUCTION FONTS — PRIORITY: MEDIUM
**What:** Custom typefaces created for shows (e.g., "GUMBAL ROUNDED" font sheets seen in leak).
**Teaches:** How shows develop proprietary typography. Letter construction, weight variants, usage specs.
**Use for:** Reference for the owner's font work — he makes custom fonts. Study how a professional show font is spec'd.

### 💡 EXPOSURE / COMPOSITION GUIDES — PRIORITY: MEDIUM
**What:** Lighting and composition reference (e.g., "unrealistic vs realistic" lighting comparisons seen in leak).
**Teaches:** How shows standardize their visual look — lighting models, color integration, compositing rules.
**Use for:** Standardizing the look across episodes. Especially useful for Gumball-style hybrid (2D+3D+live action).

### 👄 MOUTH CHARTS / VISEME GUIDES — PRIORITY: HIGH
**What:** Phoneme-to-mouth-shape mappings (e.g., 1995 Dexter's Lab "HAPPY MOUTHS" chart: A=M,B; B=EE,T — seen in leak).
**Teaches:** Professional viseme systems — how many mouth shapes, which sounds map to which.
**Use for:** DIRECTLY relevant to the owner's lip-sync work (Preston Blair visemes, Rhubarb). Compare CN mouth charts against the Blair system already in use.
