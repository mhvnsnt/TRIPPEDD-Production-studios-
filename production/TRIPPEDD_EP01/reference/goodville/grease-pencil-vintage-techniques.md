# Vintage-Cartoon Technique Reference — Blender Grease Pencil

**Source (owner-provided 2026-10-11):** "Classic Cartoons in Blender" — Youpie Toons
(@youp_zondag), 61s YouTube Short, uploaded Jun 20 2026, ~75.8K views.
https://www.youtube.com/shorts/DCzXpBqt558
Creator's description: making an old-school classic cartoon using Blender Grease Pencil —
"drawing, posing, inking, timing, and building a classic cartoon style inside Blender,"
chasing the 1930s–40s feeling: "strong poses, clean silhouettes, expressive line art,
and hand-drawn charm."

## The workflow shown (process video, no character dialogue)

1. **Rough pass** — loose sketch drawn directly in 3D space (strokes exist
   volumetrically; camera orbits the drawing). Onion skin + frame timeline visible.
2. **Refinement** — sketch cleaned while circling the camera; expression/form emerge.
3. **Inking** — smooth ink lines over the sketch; **every body part on its own layer**
   so poses can be tweaked late without redrawing ("clean but controllable").
4. **Coloring** — flat fills; motion-arc guides and drop shadows used for readability.
5. **Scene assembly** — the background is a **curved 2D backdrop strip placed in 3D
   space over a perspective grid**: a multiplane-camera-style setup recreating the
   "old cartoon parallax feeling" (the creator cites Popeye).
6. **Timing pass** — run cycle timing adjusted specifically so the feet don't glide
   over the ground.

## Stealable for Goodville production

- **Curved-backdrop multiplane parallax** — cheap, instantly sells a "classic cartoon"
  gag sequence. Prime candidate for parody-within-the-show inserts.
- **Per-body-part ink layers** — late pose tweaks without redraws; adopt as standard
  practice for any Grease Pencil work.
- **Foot-glide timing fix** — check every run/walk cycle against the ground contact;
  matches our existing obvious-defect standards.
- **"Running from something unseen"** — the short's frantic rubber-hose run never shows
  the chaser; a commenter asked what he was running from. The unseen chaser is a
  classic cheap comedy engine — pairs naturally with Amos Jr.'s "big man who vanishes"
  trait (trouble arrives, Amos is gone, nobody saw the threat either).
- **Object-fights-back beat** — the runner gets dragged by his own beach umbrella.
  Ready-made physical-comedy insert.
- **Vintage style as contrast material** — this polished golden-age look is NOT the
  Goodville house style (crude South Park-esque cutout). Use it as deliberate contrast:
  "classy flashback," dream sequence, or a parody cartoon-within-the-cartoon.
