# God Molecule Environment Pipeline\n\nGod Molecule can use a Minecraft-like deterministic world seed as the structural generator and Gaussian splats as a captured visual layer. The two representations remain separately measurable.\n\n## Composition\n\nWorld seed -> voxel/procedural macro-world -> captured references -> camera reconstruction -> Gaussian splat -> Blender/OpenUSD scene -> 2D/3D finishing\n\n## World-seed layer\n\nUse an open voxel engine/procedural generator to establish repeatable macro structure: terrain, rooms, corridors, landmarks, vegetation zones, impossible architecture, or other scene topology. The seed is part of the shot manifest so the same scene can be regenerated.\n\n## Gaussian-splat layer\n\nUse supplied photography/video as the physical appearance source. COLMAP or Meshroom can recover camera/reconstruction information; Nerfstudio and gsplat can build and render a Gaussian scene. A splat is accepted only when its source images, camera coverage, bounds and training/render artifacts are recorded.\n\n## Assembly layer\n\nBlender is the primary authoring/render boundary. OpenUSD carries layered scene data between reconstruction, procedural geometry, characters, cameras and lighting. The voxel layer supplies structure; the splat layer supplies captured appearance; canonical Mars remains an independently validated asset.\n\n## 2D path\n\nThe same environment can be flattened into plates for the show's 2D language. Those plates can go through Tonnō, Natron, OpenImageIO, OpenColorIO and editorial without pretending the source was 3D.\n\n## Why this fits God Molecule\n\n- deterministic game-like spaces\n- real captured locations\n- impossible or psychological environments\n- hybrid spaces where geometry is procedural but surfaces are photographic\n- 2D shots derived from the same world\n- 3D shots with canonical Mars moving through the same coordinate system\n\n## Hard production rules\n\n1. Seed is provenance. Record it for every generated environment.\n2. Source media stays immutable. Do not regenerate a supplied person to make the scene easier.\n3. Gaussian splats are assets, not magic. Missing training/render artifacts remain UNKNOWN or PENDING.\n4. No fake PASS. A proxy is labeled a proxy. A fallback is labeled a fallback.\n5. Coordinate systems are measured. World units, camera poses and character scale must be reconciled before animation.\n6. Every scene has a recoverable recipe: seed, source hashes, backend revisions and scene manifest.\n7. 2D and 3D are peers. A 2D plate is a deliberate production representation, not an inferior fallback.\n\n## Current open-source foundations\n\n- Luanti for deterministic voxel/world substrate.\n- World Engine for procedural world generation/history experiments.\n- COLMAP and Meshroom for camera/reconstruction.\n- Nerfstudio and gsplat for Gaussian/NeRF scene work.\n- gsplat.js for lightweight browser inspection.\n- Blender/OpenUSD for canonical scene assembly.\n\nThese are capability candidates until a real TRIPPEDD smoke run produces measured artifacts. The registry must not promote a backend merely because it is listed.\n
