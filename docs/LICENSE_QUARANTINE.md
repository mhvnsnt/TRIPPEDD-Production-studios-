# LICENSE_QUARANTINE.md — GPL/AGPL quarantine manifest

Owner law: GPL/AGPL-licensed code is **quarantined** — it is NEVER linked, imported, or wired into shipping paths. It stays isolated with this manifest until a license audit clears it. No exceptions.

## Doctrine

- **Quarantine means:** the code may exist in the repo for reference/research, but no production script imports it, no build links it, no shipped artifact embeds it.
- **Tool use ≠ code reuse:** running a GPL application as a standalone tool (e.g. opening Krita to paint) does not infect our pipeline — output artwork remains ours per the Krita/GIMP GPL FAQ doctrine. The quarantine targets *code integration*, not *tool usage*.
- **Audit path:** an item leaves quarantine only after a license audit documents a compatible relicense, a clean-room replacement, or a linking exception. The audit note goes in the table below.
- **Catalog badges:** a catalog entry for a quarantined item carries either 🚫 (copyleft code — research lane only, never wired) or ✅ with an explicit standalone-tool-use / separate-process framing and a **QUARANTINED (GPL/AGPL)** status flag (the ✅ covers tool use/output only — the code stays quarantined). ❓ is reserved for licenses genuinely not yet verified — never on an entry whose license line already says "(verified)".

## Scope: weak copyleft (LGPL / MPL / EPL / CeCILL) — recommendation PENDING OWNER VERDICT

- **The doctrine as written covers GPL/AGPL only.** Two rows on this manifest sit outside that letter:
  - **Row 63 marytts — LGPL-3.0** (verified: root LICENSE.md = LGPL-3.0 text).
  - **Row 86 G'MIC — CeCILL-2.1** (verified: gmic.eu + gmic 3.2.5 release notes). CeCILL is a French GPL-compatible copyleft license — *strong* copyleft, unlike LGPL.
- **RECOMMENDATION (Wave 8 Lane B → owner verdict required): DELIST row 63 (marytts) from quarantine** and record it under a new "weak-copyleft watchlist" note instead. Reasoning: (1) LGPL-3.0 was explicitly designed to permit dynamic linking inside proprietary/commercial works — the hazard this quarantine guards against (forced open-sourcing of shipping code, AGPL network-service source disclosure) does not apply to LGPL; (2) Wave-1 precedent already kept LGPL-2.1 Pitivi OFF this manifest — keeping marytts quarantined is inconsistent with that standing convention; (3) practical risk is near zero — marytts is a Java TTS server, not a shipping candidate, and the catalog already carries permissive TTS alternatives (Kokoro, Chatterbox, KittenTTS, Orpheus-TTS); (4) the conservative posture is preserved by a standing weak-copyleft rule: LGPL/MPL/EPL-family code is *documented and audit-gated* (dynamic-link only, no static embedding, modifications shared) but does NOT get a quarantine row.
- **G'MIC stays quarantined regardless** — CeCILL is strong copyleft (GPL-compatible), so it meets the quarantine bar on substance even if not on the letter "GPL/AGPL".
- **STATUS: row 63 stays quarantined until the owner rules.** Doctrine scope is owner-level policy; this recommendation does NOT take effect unilaterally. The Watchdog/audit lanes: treat row 63 as quarantined until the owner's verdict is recorded here.
