# TRIPPEDD / Trip Network — Programming Slate

## Purpose

This is the canonical high-level slate for the creator-owned TRIPPEDD Production Studios / Trip Network. It records the programming relationships established in the production room without inventing undeveloped details.

## Confirmed properties

### Tripped

The flagship/umbrella comedy property currently being used as the active EP01 production target. It is designed to be genre-fluid: live-action sketch, reality/street material, animation, fake media, surreal bits, music-driven pieces, and other format shifts can coexist when the material calls for them.

### The Bastard

An established TRIPPEDD show/property with reusable production material already incorporated into the production machine. Its terminal-tag work is intentionally resumable/cached so previous completed work is not unnecessarily repeated.

### In the Bushes

An established TRIPPEDD show/property in the network slate. Its existence is part of the broader programming library rather than merely an EP01 segment.

### God Molecule

A developing **Tripped recurring segment and potential standalone show/property**. The production-room discussion treats God Molecule as something that can grow beyond a single segment if the material supports it. Existing creative discussion/reference material about the God Molecule concept, including the Mars visual direction and shader work, belongs to the development record and should remain linked to future production artifacts rather than being treated as disposable chat context.

## Network model

The properties above are not required to share the same episode grammar. TRIPPEDD is intentionally a multi-format studio/network machine: a property can be live-action, scripted, animated, reality/personality-driven, music-driven, experimental, or hybrid while sharing source provenance, talent, assets, editorial infrastructure, finishing, QC, publishing, and reuse systems.

## Development rule

A segment can become a recurring segment; a recurring segment can become a show; a show can produce characters, jokes, locations, performances, shots, graphics, and other reusable assets; and finished work becomes evidence-backed development material for the next production.

## Immediate production priority

The network slate is not the blocker. **EP01 must get finished.** Infrastructure expansion should support the active production rather than becoming an excuse to postpone it.

Current EP01 evidence shows the production code/rendering path is substantially hardened, while the remaining hard blocker is source-media transport from the Drive source. The source gate must pass before another expensive full render is launched.

## Provenance

This slate is a canon-level reconstruction from production-room decisions and repository records. It is intentionally concise; detailed creative development remains in the production-conversation archive and property-specific documents.
