# Pyro Shaping Pack — SPEC H-4

A **preset library** (configuration, not code) that gives Mantaflow art
direction: five named, directed fire/smoke looks, each shipped as three
matching pieces —

1. a **Mantaflow preset** (domain + flow settings, as a JSON parameter sheet
   and as a ready-made setup inside `pyro_presets.blend`),
2. a **matching Cycles volume-shading recipe** (a `PyroVol_<look>` Principled
   Volume material, built by the same sheet), and
3. a **Natron finishing recipe** ([FINISHING-RECIPES.md](FINISHING-RECIPES.md))
   that says which studio grade the look pairs with — **LOOK 1 Pale Wash**
   or **LOOK 2 Deep Saturation** (cape-jones canon).

All parameter values are **original studio tunings**, written for this pack.
Nothing is copied from any commercial package's preset files.

## The looks

| Look | Intent | Flow | Buoyancy story | Finishing pair |
|---|---|---|---|---|
| `jet_flame` | Tight laminar burner column — hand-cannon jets, thrusters | FIRE+SMOKE, fuel 1.6, temp 2.5 | beta 2.2 (hot, fast rise), low vorticity 1.2, fast dissolve 8 | LOOK 2 |
| `campfire` | The default hero flame — hearths, torches, party plates | FIRE+SMOKE, fuel 1.0, temp 1.8 | beta 1.4, vorticity 3.2, dissolve 18 | LOOK 2 |
| `explosion_burst` | One-shot radial fireball, emits frames 1–6 only | FIRE+SMOKE, fuel 2.2, temp 3.5, subframes 4 | vorticity 5.5, time scale 0.85, dissolve 30 | LOOK 2 (LOOK 1 on flash frame) |
| `chimney_smoke` | Lazy cool smoke, long logarithmic tail | SMOKE only | alpha 0.35 gentle rise, vorticity 1.4, dissolve 45 (log) | LOOK 1 |
| `fog_bank` | Ground fog that sinks and lingers | SMOKE only, density 1.6 | alpha **−0.15** (sinks), vorticity 0.5, dissolve 60 (log), time 0.5 | LOOK 1 |

Parameter sheets: [`presets/jet_flame.json`](presets/jet_flame.json),
[`presets/campfire.json`](presets/campfire.json),
[`presets/explosion_burst.json`](presets/explosion_burst.json),
[`presets/chimney_smoke.json`](presets/chimney_smoke.json),
[`presets/fog_bank.json`](presets/fog_bank.json).
Every key in a sheet is a real Blender 4.5 Mantaflow property name
(domain: `alpha` = smoke buoyancy, `beta` = temperature buoyancy,
`dissolve_speed`, `vorticity`, `flame_vorticity`, `burning_rate`,
`flame_max_temp`, noise `noise_scale/strength/pos_scale`; flow: `density`,
`fuel_amount`, `temperature`, `smoke_color`, velocities) — verified against
Blender 4.5.3 at build time (see TEST-LOG.md: zero skipped settings).

## Use it

In Blender's Python console or headless:

```
blender -b shot.blend --python apply_pyro.py -- --look campfire
blender -b --python apply_pyro.py -- --look explosion_burst --res 72 --frames 1 64 --bake --save out.blend
```

- Pick a look → `apply_pyro.py` builds the domain (4×4×4 m), the emitter
  (shape/placement from the sheet) and the volume material in the current
  scene. Move/scale the domain and emitter to the shot; the *ratios* in the
  sheet are the look.
- Without `--bake` the cache stays in REPLAY mode (scrub to step the sim).
  `--bake` writes a resumable ALL cache and is the production path.
- Or open `pyro_presets.blend` and append the `Pyro_<look>` collection /
  `PyroVol_<look>` material directly. The `.blend` is generated by
  `build_presets.py` from the JSONs — **the JSONs + `pyro_lib.py` are the
  source of truth**; regenerate the library with
  `blender -b --factory-startup --python build_presets.py`.

## The volume-shading recipe (all looks, one shape)

`Material Output.Volume` ← **Principled Volume**:

- `Density` = sheet `density_multiplier`, `Density Attribute` = `density`
- `Color Attribute` = `flame` for fire looks (blackbody + flame colour do
  the work); pure-smoke looks use a flat `Color` tint and blackbody 0
- `Temperature Attribute` = `temperature`, `Blackbody Intensity` /
  `Blackbody Tint` from the sheet — this is what makes jet (2.6, hot tint)
  read hotter than campfire (1.8) and the burst hottest (3.2)
- `Anisotropy` from the sheet: 0 for campfire, up to 0.7 for fog (forward
  scattering is what makes fog glow around a light instead of reading grey)

## Tuning discipline

- Change a look by editing its JSON, then regenerate the `.blend`. Never
  hand-tune inside a shot file and call it the preset.
- New look = new JSON + a finishing recipe section + a line in the table
  above. Keep the spread honest: a look must differ in *behaviour*
  (buoyancy/dissolve/vorticity/emission window), not just colour.
- Wedge variants (SPEC H-2 WedgeRunner) consume these JSONs directly —
  override keys per variant instead of forking sheets.
