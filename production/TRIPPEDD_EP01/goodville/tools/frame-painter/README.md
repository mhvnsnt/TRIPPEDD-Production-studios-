# Goodville Frame Painter

Frame-by-frame animation editor for the Goodville punch sequence, built from open-source parts.

## Source
- Base drawing engine concepts from [clipanima](https://github.com/albertincx/clipanima) (MIT, mobile Flipaclip-style)
- Pulled 2026-10-12 per owner's PULL-IN DIRECTIVE

## Features
- 41 punch frames (f0240-f0280) as paintable layers
- Brushes: round, chisel/flat, airbrush, eraser
- Eyedropper to sample colors from the art
- Brush size 1-100px
- Full color wheel + hex + Goodville palette
- Zoom (pinch + buttons), pan
- Onion skin (prev red, next green)
- Play preview at 6/12/24/30fps
- Export painted frame as PNG

## Files
- `frame-painter.html` — the full app (open in browser)
- Frames load from `../../promo-15s/smart_frames_fixed/`
