# Steal Like An Artist — In the Bushes
## Study materials for lo-fi handmade animation

> In the Bushes is kid-drawing, crude lo-fi, handmade deadpan (12 oz. Mouse /
> Home Movies tone). The style is INTENTIONAL — polish that erases it is a defect.
> These materials teach how professionals do "crude" at scale without losing control.

## Loose hand-drawn at scale

- **Ed, Edd n Eddy** (CN leak) — the master of loose, wobbly, handmade-feeling
  animation produced on a real TV pipeline. Study how they keep the wobble
  consistent across episodes and animators.
  Check `steal-like-artist/cn-gigaleak/CN-GIGALEAK-CATALOG.md` for pull status.
- **Home Movies / 12 oz. Mouse** — reference tone (not in leak, but the north star).

## What "crude on purpose" requires

Counter-intuitive truth: deliberate crudeness needs MORE documentation, not less.
Without model sheets, "crude" drifts into "sloppy" within three scenes.

**Template:** `../steal-like-artist-templates/character-model-sheet-template.md`
Build sheets that define the crudeness: line weight range, wobble amplitude,
which rules break and which never do. The Bushes bible already has MR. GOLD
COLOR LOCK — extend that discipline to every character.
