# Rocket Next Build Order

1. **Manual Edit → GitHub**
   - bind editor Save actions to real artifact serialization;
   - create operation receipts;
   - validate before checkpoint;
   - checkpoint and commit actual artifact paths;
   - push through the independent bridge;
   - refresh from resulting commit.

2. **Animation Blocking Workspace**
   - use the same artifact receipt and checkpoint pipeline;
   - write actual Blender actions/keyframes/scene state;
   - render a review preview before publish;
   - never represent canvas-only keyframes as authoritative.

3. **Editorial Timeline / Shot Assembly**
   - consume the authoritative physical/editorial source timeline and existing shot metadata;
   - save a real sequence/timeline artifact;
   - preserve source provenance and shot IDs;
   - publish through the same bridge.

4. **Only then expand editor breadth**
   - modeling, rigging, facial, weight paint, hair, materials, camera/lighting, compositing/VFX and audio should all reuse the same durable publish substrate.

## Hard stop

Do not add a new editor merely because it looks useful if its Save button cannot eventually produce an authoritative artifact receipt. UI breadth without durable artifact persistence is not production progress.
