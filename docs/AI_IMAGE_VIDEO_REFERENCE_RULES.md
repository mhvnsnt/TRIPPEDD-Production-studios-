# AI Image & Video Reference Rules

## Standing production rule

When the user supplies photographs of a real subject as reference/usable production images:

1. The supplied photographs are the source of truth for identity and likeness.
2. Image editing means editing the supplied image, not generating a replacement person.
3. Preserve the subject's identity, facial structure, proportions, hair/dreadlock structure, facial hair, distinctive features, asymmetries, and other visible characteristics unless the user explicitly requests a change.
4. Do not substitute a generic/generated character that merely resembles the source.
5. Do not reinterpret, redesign, beautify, age/de-age, or otherwise alter the subject's likeness unless explicitly requested.
6. For multi-angle sets, treat the supplied views as measurements of the same physical subject and use them together to maintain continuity.
7. For image-to-video work, animate/transform the supplied source subject. Do not regenerate the character as a new identity.
8. If the user asks for a WRITTEN PROMPT, provide the prompt as text. Do NOT trigger image generation merely because the prompt describes an image or video.
9. Trigger image generation only when the user actually asks to create/generate an image (or asks for an image edit and a usable source image is present). A request to write a prompt is not an image-generation request.
10. Reference fidelity and identity preservation take priority over visual spectacle or generative invention.

## Current God Molecule reference workflow

The established character reference set consists of the user's supplied front, left, right, and back head/face views. These are to be treated as the canonical reference set for character-building and image/video production for God Molecule.

For rotation/video generation, the intended workflow is:
**FRONT -> LEFT -> BACK -> RIGHT -> FRONT**

The result should look like the exact supplied subject being animated/filmed, not like a newly generated person inspired by the references.

## Scope

These rules apply to future God Molecule and TRIPPEDD Production Studios image/video workflows unless the user explicitly overrides them.
