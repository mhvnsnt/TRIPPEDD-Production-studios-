## 5. Production pipeline with gates

```
SCRIPT (draft) → OWNER READ → VOICE RECORD → STORYBOARDS → ANIMATIC
→ STILLS GATE (owner approves look — NOTHING animates before this)
→ ANIMATION → EDIT → MIX → QC (eyes-on verification) → MASTER → NETWORK DELIVERY
```

Voice-first: real TV records dialogue before animating. The animation pass is timed to the recorded voice — the owner's voice decision unlocks animation.

Gate rules:
- **Script gate:** owner reads; nothing locks until he says so.
- **Voice gate:** owner approves the voice (William test → decision).
- **Stills gate:** owner approves turnaround + locations + boards. No animation before this, ever.
- **QC gate:** the deliverable verification law applies — frames sampled across the whole timeline, style-lock checked, audio duration + non-silent verified, delivery path confirmed (Messenger for audio/video).

## 6. Per-episode delivery standard

Every episode ships:
1. Locked script (owner-approved)
2. Voice record (owner-approved voice)
3. Storyboards + animatic (owner-approved stills)
4. Animated episode (never a stills slideshow — the EP02 slideshow incident is law)
5. Full audio: dialogue + SFX + music bed, mixed
6. Title sequence + **end credits** (`END-CREDITS.md`)
7. Unused-audio archive with manifest (for later episodes/segments/commercials)
8. CUT-NOTES.md / production notes
