## Grading rules

1. Skin tones never drift episode to episode — sample against this sheet.
2. Aaron's tee is always `#3A3A3A`. If it looks black, it's wrong; if it looks light gray, it's wrong.
3. Night scenes: crush the blacks, let the phone glow carry.
4. No teal-and-orange blockbuster grading. This is a deadpan sitcom, not a trailer.
5. The 3D device (when used): the 3D render is deliberately TOO detailed and glossy vs. the flat 2D — the mismatch is the joke.
