# WIZARD GANG BIBLE — FORMAT MODELS NOTE

Which format model each section of `SHOW-BIBLE-SKELETON.md` follows, and why.
Structure only — no other show's content was copied into Wizard Gang.

## The staged template

`show-bible-template.md` (same folder) is a verbatim copy of
`mhvnsnt/God-molecule-production-stage`,
`docs/steal-like-artist-templates/show-bible-template.md` (4,137 B, version
2026-10-12). The skeleton follows that template's section order exactly:
1 Series Overview, 2 Character Applications, 3 Environmental Parameters,
4 Story Premises, 5 Tone & Style Guide. Nothing was added to the template file
itself — provenance lives here, not in the staged copy.

## Section-by-section models

| Skeleton section | Follows | Why |
|---|---|---|
| Header / status block + "skeleton, not canon" | God Molecule unified bible (`mhvnsnt/God-Molecule-Show-Studio`, `docs/GOD-MOLECULE-UNIFIED-BIBLE.md`) | God Molecule states authority order + draft status up front and tags every section with provenance (`[A]` / `[B-KEEP]` / `[C]` / `[W2]`). The WG skeleton copies that discipline: every verified fact carries its source doc; gaps are marked OPEN, never invented. |
| §1 Series Overview (Hook / Protagonist / How We Got Here / Immutable Laws / What's New / Emotional Thesis) | Show-bible template §1 (the 6-step pattern) | This is the template's own spine. The WG version keeps the six sub-slots and fills only "How We Got Here" with verified production history (EP01 v10, "THE SUMMIT", EP02 correction). The verified production laws sit under Immutable Laws, clearly labelled as production rules — not story laws, which are still owner decisions. |
| §2 Character Applications (9 blocks, same form) | Show-bible template §2 | The template's rule is "copy this block for EVERY character, same form every time." WG does that for all nine. The only filled fields are the verified ones (name + Chatterbox voice reference); everything else is an `OWNER DECISION` slot, so no character gets invented backstory. |
| §3 Environmental Parameters (world / locations / world rules) | Show-bible template §3 + Gumball bible (`mhvnsnt/cn-gigaleak-gumball`, `Gumball_Bible_text.pdf`) | Template gives the shape (setting as a character + key-locations table + world rules). Gumball's bible is the professional proof of that shape: one premise paragraph ("The Show"), then the town itself as a character (Elmore, pop. 20,000), then recurring locations before any episode content. WG's §3 is empty on purpose — no world exists on file — but the Gumball order says: place first, premises second. |
| §4 Story Premises (8 slots) | Show-bible template §4 | Template asks for 8–12 episode springboards, title + 2–3 sentences each, as proof the concept generates stories. WG lists 8 blank slots and states the order rule explicitly: premises come AFTER the world (§3) is decided, not before. |
| §5 Tone & Style Guide | Show-bible template §5 + Dream Girl bible (`mguide`, `docs/DREAM-GIRL-BIBLE.md`) | Template gives the four sub-slots (art style / comedy-drama engine / what the show is NOT / content boundaries). Dream Girl is the model for how owner rulings land in a bible: each lock is dated and attributed ("owner law, 2026-11-10 10:10 CT — 'don't whitewash…'"). WG's §5 copies that habit for its verified production facts and leaves the creative calls as dated owner decisions when they arrive. |
| §6 Episode Structure | Samurai Jack / Primal craft extraction (`mhvnsnt/samurai-jack-repo`, `craft-for-our-shows/CRAFT-EP01.md`) | That doc is a METHOD extraction (environment-first minutes, one sense as channel, rhythm not coverage, rationed cameos, color keys), written for Mochiichao EP01. WG's §6 lists those mechanics as a menu to accept/reject — method only, none of Mochiichao's content — because WG has no episode structure on file at all. |
| §7 Season Structure | God Molecule unified bible §11 | God Molecule's "nine-lives arc" shows how a season gets a spine without plotting any single episode (nine episodes = nine lives, finale reversal template). WG's §7 is only the three owner questions that would produce WG's own equivalent — no arc is proposed. |
| §8 How this skeleton grows (a / b / c) | Mystery Coast seed bible (`mhvnsnt/mystery-coast-ghosted`, `SHOW-BIBLE.md`, 1,040 B) | Mystery Coast proves option (b): a seed can lock concept + twist + tone in ~1 KB and mark the rest "Concept locked. Full bible TBD." §8 maps each of the three undecided options onto this skeleton so whichever the owner picks, the work already done still fits — no option is picked here. |
| §9 Provenance & Open Gaps | God Molecule unified bible §17–§18 | God Molecule ends with reconciliation notes (unresolved discrepancies, owner decides) and an explicit open-gaps list. WG's §9 copies that: sources used, what was deliberately left out because it could NOT be verified (mouthless-90%, two-styles cap, all-nine void faces), and the open gaps. |

## What was NOT taken from the models

- No character, place, line, joke, or piece of lore from any model show.
- No Gumball / God Molecule / Mystery Coast / Dream Girl / Mochiichao content
  appears in the skeleton. Only section shapes, the provenance habit, and the
  seed-bible growth pattern were borrowed.
- The Gumball bible was read via text extraction for structure (logline →
  premise paragraph → town-as-character → character pages → recurring
  locations). Its art-heavy pages do not extract as text; the structure note
  above is drawn from the extractable text only.
