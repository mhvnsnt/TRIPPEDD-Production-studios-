# TRIPPEDD NETWORK — Programming Grid

Status: `ACTIVE` (owner 2026-10-10). Mars Network programs like a network, not a feed.
Companion docs: `PROGRAMMING-AND-INTERSTITIAL-GRAMMAR.md` (the why), `TRIPPEDD-NETWORK-SLATE.md` (the properties).

## Principle

Rotation, not bursts. Every property gets its block; no property owns the channel
for more than its slot. Human rhythm keeps YouTube's trust systems calm; network
rhythm gives the audience a habit. (The 2026-10-10 rapid-fire upload bursts that
triggered YouTube's "still checking your content" friction are the failure mode
this grid replaces.)

## Dayparts (America/Chicago)

- **MORNING (9a–12p):** Shorts rotation — 1 Short, property cycles daily through the list above.
- **AFTERNOON (12p–5p):** Feature slot — rotates type, not just property: commercial → segment drop →
  WIP/progress piece → music → fake ad → promo. Never the same type two days running.
- **EVENING (6p–9p):** reserved for premiere nights only. Dark on normal days.
- **LATE (9p+):** the weird block — experimental, interstitials, Adult Swim energy. Occasional, not daily.

## Weekly skeleton

- **Mon–Thu:** 1–2 drops/day from the dayparts above, properties and types rotating.
- **Wed–Thu:** promo spots for the week's premiere (the run-up).
- **Friday 7p CT: PREMIERE NIGHT** — the week's anchor. Episode, trailer, showcase, short film.
  Announced 48h ahead. This is the only fixed appointment on the grid.
- **Sat–Sun:** lighter rotation — Shorts, music, wild cards, repeats of the week's best performer.

## Rotation rules

1. Max 2 uploads/day. Min 4 active days/week.
2. No property in the same daypart twice within 7 days.
3. No type repeat in the afternoon slot two days running.
4. Every long-form upload ends with a STAY TRIPPEDD bumper card; Shorts carry the card
   as an end frame or pinned comment.
5. Premiere gets promo spots Wed–Thu before it. No surprise premieres.
6. If YouTube shows any friction (checks stalling, warnings, strikes): drop to 1/day
   until clear, then resume. Never publish through a warning.
7. **Owner OK still required per upload.** The YOUTUBE POSTING RULE stands — this grid
   schedules *what* goes, never auto-publishes. No autonomous YouTube posting.

## What "network rhythm" means in one line

Different shows, segments, commercials, and network pieces rotating through the day
and the week, premieres on Friday night, bumpers between everything — the audience
can feel the schedule without being told it.
