**Network:** TRIPPEDD NETWORK.
**Show bible:** `docs/show/SHOW-BIBLE.md` in `mhvnsnt/SMOKE-MIRROR-S-` (game canon: `docs/constitution/`, 24 frozen sections).

## What the show is

Cut from first-person exploration footage (game capture or 2D/3D animated at studio discretion — owner gave full reins on medium). Dark, quiet, atmospheric. **Voiceless by law** — no narration, no explanatory text, no UI/HUD.

Segment grammar:

```
YOU CANNOT SEE → YOU REVEAL → (understanding is the viewer's, never stated)
```

The network's anti-exposition show: where other segments talk, this one withholds.

## Laws (show form)

- Never explain the trick. Never announce the discovery.
- Darkness, silence, and empty space are content — silence is scheduled like a cue.
- Discovery may be missed by the viewer. That is correct.
- Never show undiscovered systems, UI, menus, or HUD. Clean first-person camera only.
- POV locked: first-person only. No third-person, no cutaways, no drone shots.

## First intended use

Embedded atmospheric/surreal segments inside TRIPPEDD episodes. Short, self-contained, unexplained units for the block.

## Layout

- `segments/` — produced segment units (numbered, with segment notes).
- `stills/` — key frames / lookdev.
- `audio/` — footsteps, hums, room tone, scheduled silence (no voice, ever).

## Art style lock

Per the bible's visual grammar + the network art style law: darkness-first palette (see bible), first-person POV, no AI-slop deviation. Check against the bible before delivery.
