# TRIPPEDD NETWORK — Bump Guide

**What these are:** Original interstitial bump segments for MarsNetwork, in the
*form* of Adult Swim bumps (black text cards, deadpan one-liners, network IDs,
ambient mood pieces) but 100% our own content. No AS copy, no AS logo.

**Formats:** Every bump ships in two orientations:
- `vert/` — 720×1280 (9:16), for YouTube Shorts
- `horiz/` — 1280×720 (16:9), for long-form interstitials / premieres

All 30fps, H.264, silent. Add music at mix if you want the lo-fi AS feel —
silence is also on-brand for the text cards.

**Brand tag:** `[trippedd]` — our version of the corner logo sign-off.

## Posting Rotation (anti-spam rules)

The duplicate-upload incident (Oct 2026) is why this exists. Follow it:

1. **One bump per day max** on Shorts. Never batch-upload the same day.
2. **Never post the same bump twice.** Ever. If you want to rerun one, wait 30+ days.
3. **Rotate categories:** ID → joke → promo → ambient → joke → ID … don't run two promos back-to-back.
4. **Keep a log.** Every upload gets one line in `POST-LOG.md` (date, bump #, URL). Check the log before posting anything.
5. **Horiz versions** are for slotting between segments in long-form episodes/premieres — not for Shorts.
6. **Retire after 3 months.** When a bump feels stale, generate a fresh batch with new jokes. The script is `gen_bumps.py` — swap the copy, rerun.

## Making More

Edit the `BUMPS` list in `gen_bumps.py` (copy + render function), rerun:
`cd ~/workspace/trippedd-bumps && python3 gen_bumps.py`

Keep the voice: lowercase, deadpan, self-aware, never mean. Punch at the
network itself, never at the viewer.
