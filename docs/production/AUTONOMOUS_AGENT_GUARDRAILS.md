# Autonomous agent guardrails — stop bullshit, use real tools

## Law

1. **Show canon first** — MARS is a floating head; EP01 / linework / GNM donors beat generic humanoid pipelines.  
2. **Donor first** — never hand-roll what GNM / ICT / owner plates already provide.  
3. **Pixels veto geometry** — numerical PASS without reopened PNG + SHA is not promotion.  
4. **UNKNOWN ≠ PASS** — missing receipt = blocked.  
5. **Protected components** — eyes, lids, oral, hair locks are assets; snapshot before change.  
6. **No invented runtime** — no fake ROCKET_LIVE_SESSION_URL; HTTP 200 ≠ authoritative without operationId + SHA.  
7. **Reset over compound error** — if lineage is shredded, return to original GLB (see PRODUCTION_RESET).
