# TRIPPEDD network — Programming Slate

## Canonical naming

- **Show:** Trippedd
- **Network:** TRIPPEDD network
- **Studio:** TRIPPEDD Production studios

This is the canonical high-level slate for the creator-owned TRIPPEDD Production studios / TRIPPEDD network. It records programming relationships without inventing undeveloped details.

## Confirmed properties

### Trippedd

The flagship/umbrella comedy property currently being used as the active EP01 production target. It is genre-fluid: live-action sketch, reality/street material, animation, fake media, surreal bits, music-driven pieces, and other format shifts can coexist when the material calls for them.

### The Bastard

An established TRIPPEDD network show/property with reusable production material already incorporated into the production machine. Its terminal-tag work is intentionally resumable/cached.

### In the Bushes

An established TRIPPEDD network show/property in the broader programming library.

### God Molecule

A developing **Trippedd recurring segment and potential standalone show/property**. Existing Mars visual direction and shader work belong to the development record and should remain linked to future production artifacts rather than being disposable chat context.

## TRIPPEDD network bumper / ident

The first short production proof will also function as a **10–20 second TRIPPEDD network commercial/ident**. It is not an episode and not a throwaway synthetic test. It is a miniature expression of the network's actual programming identity.

The visual grammar can mutate rapidly while retaining a recognizable network identity: a recurring Trip/Trippedd mark or card language can be remixed through animation, typography, surreal transitions, psychedelic treatment, live-action-derived textures, and flashes of the network's different properties. The piece should feel like one coherent network ident rather than a slideshow.

The initial concept pool includes the visual worlds of **Trippedd**, **The Bastard**, **In the Bushes**, and **God Molecule**, with God Molecule's Mars/shader direction treated as development material rather than invented finished footage.

## Network model

The properties are not required to share the same episode grammar. TRIPPEDD network is intentionally a multi-format studio/network machine: a property can be live-action, scripted, animated, reality/personality-driven, music-driven, experimental, or hybrid while sharing source provenance, talent, assets, editorial infrastructure, finishing, QC, publishing, and reuse systems.

## Development rule

A segment can become a recurring segment; a recurring segment can become a show; a show can produce characters, jokes, locations, performances, shots, graphics, and reusable assets; finished work becomes evidence-backed development material for the next production.

## Production gate

The network ident is the designated short end-to-end proof. **No real episode run/cut is launched until the 10–20 second proof completes the hardened production path and passes final QC.**

The proof must exercise the same critical production contracts used by real work: source ingest/materialization, analysis, editorial evidence, generated/animated material, assembly, media encoding, timeline output, artifact validation, and machine-readable telemetry/recovery behavior where applicable.

## Immediate production priority

Infrastructure expansion supports production; it is not a substitute for finishing EP01. The source gate and short proof exist specifically to prevent another expensive blind render.
