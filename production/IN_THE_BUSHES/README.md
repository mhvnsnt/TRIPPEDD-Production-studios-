## Style lock (owner 2026-10-09)

**A 12 oz. Mouse / Home Movies type of show.** Ultra-crude, lo-fi, deadpan.
The handmade kid-drawing aesthetic is the visual contract ("keep it handmade").
Polish that erases the handmade quality is a defect, not an improvement.

## Production pipeline (mirrors Wizard Gang)

```text
character-art (source) → character-cards/ → EP01/ → segments → pilot → episodes
```

- `character-cards/` — one card per character: visual lock, expressions, status, source. No invented traits.
- `art/` — pointer to the source art (never duplicated).
- `EP01/` — the pilot: screenplay, segments, stills, audio.
- Future episodes: `EP02/`, `EP03/`, … same skeleton.

## The Bushes rule

Keep it handmade. Busch reads as a bush that acts, not a mascot costume.
Foliage is the body; deformation is the performance. Mr. Gold and Mr. Tree
are separate characters with separate builds — never merged, never conflated.

## Network tie-in (production-bible only, never stated on screen)

Per the Smoke & Mirrors show bible "Network tie-ins": the secretly unspoken
reason Busch and other inanimate objects come alive ties to Smoke & Mirrors'
secret prison dimension. This is never said out loud in the show.
