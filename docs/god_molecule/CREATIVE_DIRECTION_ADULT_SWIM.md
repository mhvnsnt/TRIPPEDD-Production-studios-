# God Molecule — Creative Direction (Adult Swim register)

Production systems are strict. The show is not.

## Tone

- Cosmic scale + basement-budget intimacy in the same cut  
- Mars is sincere, wrong, and occasionally terrifying  
- Body and mind leak into the environment (mouths, eyes, architecture that shouldn’t breathe)  
- Jokes land like philosophy; philosophy lands like a bad trip  
- Nested worlds are literal production tech (seeds, layers, splats) **and** cosmology  

Allowed: violence as cartoon metaphysics, sexual weirdness as character texture, blasphemy as set dressing, long awkward silences, punchlines that refuse to resolve.

Not allowed in pipeline: replacing `MARS_CANONICAL`, faking renders, calling telemetry a creative final.

## Visual languages (use deliberately)

| Mode | Feels like | Technical lane |
|------|------------|----------------|
| Physical | You could cut yourself on it | Mesh + lighting + optional splat detail |
| Memory / broadcast | Soft, wrong, edited | 2D / generative / hybrid comp |
| Hallucination | Rules break on purpose | Hybrid + intentional continuity errors |
| Diagram / god-cam | Explanatory and ominous | Motion graphics over seeded world |

## Mars performance

- Lip-sync only from real Rhubarb (or explicit mute / stylized non-sync)  
- Jaw and tongue are anatomy, not stickers  
- Eyes can lie; the mouth should still open  

## Episode craft

Treat each cold open as a thesis. Let the mid-episode digress into a smaller world with its own seed. End on an image that recontextualizes the joke, not a button that explains it.

When in doubt: **funnier and stranger, still measurable.**
